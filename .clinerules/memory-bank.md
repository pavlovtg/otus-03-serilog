# Memory Bank Rule

## При старте каждой задачи

- Прочитать все файлы `docs/ai/memory-bank/` перед любыми действиями.
- Файлы читать в порядке: `projectbrief.md` → `productContext.md` → `systemPatterns.md` → `techContext.md` → `activeContext.md` → `progress.md`.

## При завершении каждой задачи

- Обновить `activeContext.md` — текущий фокус и следующий шаг.
- Обновить `progress.md` — перенести выполненное в «Выполнено», добавить новые пункты.
- Обновить другие файлы только если изменилась архитектура, технологии или контекст проекта.

## Формат файлов

- Только буллеты, одно предложение на пункт, без вводных фраз.
