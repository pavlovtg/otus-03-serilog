# Product Context

- **Что делает:** предоставляет structured logging API для .NET — запись событий с именованными свойствами вместо plain text.
- **Ключевые сценарии:** логирование в консоль/файл/внешние sinks; обогащение событий (enrichment); фильтрация по уровню.
- **Проблема, которую решает:** традиционные логгеры теряют структуру данных; Serilog сохраняет свойства как объекты для последующего анализа.
- **Пользователи:** .NET-разработчики, DevOps-инженеры, интеграторы внешних sinks.
