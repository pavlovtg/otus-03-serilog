# Покрытие модуля тестами

## Контекст

Задача — написать unit-тесты для существующего класса по паттернам проекта.

Правила проекта:

- Тестовый фреймворк — xUnit, mock-фреймворки не используются.
- Тесты зеркалируют структуру `src/`: класс `src/Serilog/Core/Foo.cs` → тест `test/Serilog.Tests/Core/FooTests.cs`.
- Покрытие — не менее 80% веток и публичных методов класса.
- Агент определяет путь к тест-файлу автоматически по правилу зеркальной структуры.
- Агент записывает готовый код напрямую в файл, не показывает в чате.

Как применять: укажи имя класса и его namespace в промпте ниже, остальное агент определит сам.

## Пример промпта

```
Напиши unit-тесты для класса {ClassName} из namespace {Namespace}.

Требования:
- Прочитай исходный файл класса и все связанные типы.
- Определи путь к тест-файлу по правилу зеркальной структуры src/ → test/Serilog.Tests/.
- Покрой не менее 80% публичных методов и веток логики.
- Используй xUnit (Fact / Theory), без mock-фреймворков.
- Следуй паттернам существующих тестов в test/Serilog.Tests/.
- Запиши тесты напрямую в тест-файл, в чате код не показывай.
- После записи выполни: dotnet build Serilog.sln
- Убедись, что все новые тесты проходят.
```

## Критерии готовности

- Тест-файл создан по зеркальной структуре.
- Покрытие публичных методов класса — не менее 80%.
- `dotnet build Serilog.sln` завершается без ошибок.
- Все новые тесты зелёные.
