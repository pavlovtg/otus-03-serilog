# Рефакторинг без изменения поведения

## Контекст

Задача — привести существующий код к актуальному code style без изменения логики.

Правила проекта:

- Правила code style описаны в `docs/code-style/csharp-code-style.md`.
- Логика и публичный API класса не меняются.
- После рефакторинга запускается весь тестовый suite (`dotnet test`), а не только тесты конкретного класса.
- Агент записывает изменения напрямую в файл, не показывает diff в чате.

Как применять: укажи имя класса и его namespace в промпте ниже.

## Пример промпта

```
Выполни рефакторинг класса {Namespace.ClassName}.

Выполнить следующий рефакторинг:
- {Описание рефакторинга}

Требования:
- Прочитай docs/code-style/csharp-code-style.md и применяй все правила.
- Не меняй логику, публичный API и сигнатуры методов.
- Приведи форматирование, именование и стиль к актуальным правилам.
- Запиши изменения напрямую в исходный файл, в чате diff не показывай.
- После изменений выполни: dotnet test
- Убедись, что все тесты остались зелёными.
```

## Критерии готовности

- Код соответствует `docs/code-style/csharp-code-style.md`.
- Логика и публичный API класса не изменились.
- `dotnet test` завершается без ошибок и падений.
