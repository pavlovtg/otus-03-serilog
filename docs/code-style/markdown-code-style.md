# Markdown Code Style

## Форматирование

- Кодировка — UTF-8.
- Окончания строк — LF.
- Trailing whitespace не допускается (MD009).
- Файл заканчивается пустой строкой (MD047).

## Заголовки (MD022)

- Заголовок предваряется пустой строкой (кроме начала файла).
- После заголовка следует пустая строка.

## Пустые строки

- Не более одной последовательной пустой строки (MD012).
- Списки окружаются пустыми строками (MD032).

## Ссылки (MD034)

- Голые URL не допускаются — оборачивать в `<URL>` или `[текст](URL)`.

## Списки

- Списки (маркированные и нумерованные) окружаются пустыми строками (MD032).
- Вложенные списки — отступ 2 или 4 пробела (единообразно в файле).

## Общие правила

- Одна пустая строка между разделами.
- Код оборачивается в backtick-блоки с указанием языка.
