# Создание skill для работы с промтами в репозитории

## Роль

- Ты — разработчик, подготавливающий репозиторий для работы с AI-ассистентом Cline.

## Контекст

- В репозиторий нужно добавить структуры для работы с Cline.

## Задача

- Создать skill `create-prompt-from-template` как файл `SKILL.md` в папке `.clinerules/skills/create-prompt-from-template/`.
- Формат skill: YAML frontmatter с полями `name`, `description`, `allowed-tools`, затем тело с пошаговым workflow на русском языке.
- Skill активируется по команде `create prompt`.
- Skill создаёт файл промта в папке `homework/prompts/`.
- Имя файла: `<index>-<codename>.md`, где `<index>` — максимальный существующий индекс + 1 с ведущим нулём, `<codename>` — краткое название латиницей через дефис, запрашивается у пользователя.
- Шаблон промта зафиксировать в `.clinerules/skills/templates/prompt.md`.

## Требования к шаблону промта

- Язык: русский.
- Одно предложение вместо абзаца.
- Структура разделов: Роль / Контекст / Задача / Требования, один буллет-плейсхолдер в каждом.
- Убирать вводные фразы и дублирующие пояснения.
- Цель: экономия токенов контекста без потери смысла.
