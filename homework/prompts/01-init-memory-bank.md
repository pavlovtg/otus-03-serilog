# Инициализация Memory Bank

## Роль

- AI-ассистент (Cline), настраивающий memory bank и rules для проекта.

## Контекст

- Проект без memory bank и без правил его использования.

## Задача

- Инициализировать memory bank командой `init memory bank in folder /docs/ai/memory-bank`.
- Создать `.clinerules/memory-bank.md` — правило читать и обновлять memory bank при каждой задаче.

## Требования

- Все создаваемые файлы максимально компактны: буллеты, одно предложение вместо абзаца, без вводных фраз.
- Цель: экономия токенов контекста без потери смысла.
