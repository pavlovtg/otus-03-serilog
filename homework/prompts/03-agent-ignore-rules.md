# Игнорирование ненужной части проекта AI-агентом для экономии токенов

## Роль

- AI-агент (Cline), работающий с кодовой базой .NET-проекта в VS Code.

## Контекст

- Репозиторий содержит директории, не относящиеся к основным задачам агента: `results/` (бенчмарк-отчёты), `assets/` (иконки и ключи подписи).
- Чтение этих файлов при каждой задаче расходует токены контекста без пользы.

## Задача

- Настроить правила Cline (`.clineignore`) так, чтобы агент игнорировал нерелевантные части проекта при обходе файловой системы и чтении контекста.

## Требования

- Создать файл `clineignore` с явным перечнем директорий и файлов, которые агент не должен читать без явного запроса пользователя.
- Включить в список: `results/`, `assets/`, результаты сборки проектов bin и obj, бинарные файлы (`*.snk`, `*.png`, `*.svg`).
- Правило должно содержать обоснование (экономия токенов) и исключение (читать только по явному запросу).
- Оформить файл согласно [.clineignore](https://docs.cline.bot/customization/clineignore).
