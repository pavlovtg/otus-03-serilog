# Отчёт о выполнении домашнего задания

## Роль

- Ты — разработчик, подготавливающий репозиторий для работы с AI-ассистентом Cline.

## Контекст

- В репозиторий нужно добавить структуры для работы с Cline.

## Задача

Сформировать отчет о выполненной домашней работе.

## Требования

- Задание находится в файле 'homework/assignment.md';
- Отчет положить в файл 'homework/report.md';
- Отчет должен содержать информацию о выполненной работе.
- Использованные запросы лежат в 'homework/prompts/';
